项目筛选器的视觉形态很像一组标签，但它实际上是一组会立即改变结果的命令。语义不清会让读屏用户难以判断当前条件。

## 使用按钮表达状态

每个条件使用原生 `button`，当前选中项通过 `aria-pressed="true"` 表达。用户不需要离开页面，结果计数与空状态在原位更新。

## 稳定的尺寸比华丽动画更重要

项目卡片的封面比例、描述行数和标签区域都有明确约束。筛选时只改变哪些卡片参与布局，不让控件本身随文本长度跳动。

## 保留无 JavaScript 路径

默认 HTML 包含所有已发布项目。JavaScript 只在加载后注册筛选行为，因此脚本失败时内容仍然完整，搜索引擎也能读取项目链接。
