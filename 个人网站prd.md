# 个人网站 PRD 文档

## 1. 项目概述

### 1.1 项目背景
开发一个部署在 GitHub Pages 上的个人网站，用于展示个人信息、作品集和技术能力。

### 1.2 项目目标
- 建立个人品牌形象
- 展示专业技能和项目经验
- 分享技术文章和思考
- 提供联系方式

### 1.3 目标用户
- 潜在雇主/HR
- 技术同行
- 合作伙伴
- 对作者感兴趣的人

## 2. 模块与页面映射总览

### 2.1 模块清单

| 模块       | 对应页面   | 页面路径           | 优先级 |
| ---------- | ---------- | ------------------ | ------ |
| 首页模块   | 首页       | `/`                | P0     |
| 关于模块   | 关于页     | `/about`           | P0     |
| 作品集模块 | 作品列表页 | `/projects`        | P0     |
| 作品集模块 | 作品详情页 | `/projects/[slug]` | P0     |
| 博客模块   | 博客列表页 | `/blog`            | P1     |
| 博客模块   | 博客详情页 | `/blog/[slug]`     | P1     |
| 博客模块   | 标签页     | `/blog/tags/[tag]` | P2     |
| 联系模块   | 联系页     | `/contact`         | P1     |
| 全局模块   | 404 页     | `/404`             | P2     |
| 全局模块   | 搜索页     | `/search`          | P2     |

### 2.2 页面与模块关系图

```
首页 (/)
├── 引用：关于模块（简介摘要）
├── 引用：作品集模块（精选项目）
└── 引用：博客模块（最新文章）

关于 (/about)
└── 引用：联系模块（CTA）

作品列表 (/projects)
└── 跳转 → 作品详情 (/projects/[slug])

博客列表 (/blog)
├── 跳转 → 博客详情 (/blog/[slug])
└── 跳转 → 标签页 (/blog/tags/[tag])

联系 (/contact)
└── 引用：联系模块（表单 + 社交链接）
```

## 4. 页面响应式布局规范

### 4.1 断点定义

| 断点    | 宽度           | 布局变化                 |
| ------- | -------------- | ------------------------ |
| Mobile  | < 640px        | 单列，汉堡菜单，隐藏 TOC |
| Tablet  | 640px - 1024px | 两列网格，侧栏收起       |
| Desktop | > 1024px       | 三列网格，显示 TOC 侧栏  |

### 4.2 各页面响应式要点

| 页面      | Mobile             | Tablet        | Desktop       |
| --------- | ------------------ | ------------- | ------------- |
| 首页 Hero | 头像上方，文字下方 | 左右布局      | 左右布局      |
| 首页项目  | 单列               | 两列          | 三列          |
| 关于技能  | 单列               | 两列          | 三列          |
| 作品列表  | 单列               | 两列          | 三列          |
| 博客列表  | 单列               | 单列          | 单列          |
| 博客详情  | 隐藏 TOC           | 隐藏 TOC      | 显示右侧 TOC  |
| 联系      | 表单单列           | 表单+信息两列 | 表单+信息两列 |

### 6.4 部署方案

#### 域名说明
- 使用 GitHub Pages 默认域名：`https://<username>.github.io`
- 无需配置 CNAME 文件，无需自定义域名

#### GitHub Actions 配置

```yaml
# .github/workflows/deploy.yml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

#### GitHub 仓库设置
1. 进入仓库 **Settings → Pages**
2. **Source** 选择 `GitHub Actions`
3. 推送代码到 `main` 分支后自动部署
4. 部署完成后访问 `https://<username>.github.io`
